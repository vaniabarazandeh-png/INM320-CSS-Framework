
# INM320 - CSS Framework

## Project Overview

A responsive Purity UI Dashboard developed for INM320
Web Development II at Seneca Polytechnic.

The dashboard is based on the provided Figma design
and recreated using the Bootstrap CSS framework.

## Technologies Used

- HTML5
- CSS3
- Bootstrap 5
- Bootstrap Icons
- JavaScript
- Chart.js
- Node.js
- lite-server
- Git and GitHub

## Assignment Requirements

- Recreated the provided Figma dashboard design.
- Switched Sales Overview and Active Users.
- Assigned both charts 50% width on desktop.
- Implemented a mobile-first responsive layout.
- Customized the default Bootstrap styling.

## Additional Features

- Interactive line and bar charts.
- Bootstrap settings modal.
- Bootstrap form elements.
- Collapsible mobile navigation.
- Responsive statistics cards.
- Responsive projects table.
- Custom CSS variables.
- Remote GitHub repository.

## Installation Instructions

Make sure Node.js is installed.

Install the project dependencies:

    npm install

Start the development server:

    npm start

Open the dashboard at:

    http://localhost:3000

## Responsive Design

The dashboard adapts to mobile, tablet and desktop
screen sizes using the Bootstrap grid system and
custom min-width media queries.

## Design Reference
